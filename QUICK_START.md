# ⚡ Quick Start Guide

Get your attendance system up and running in 5 minutes!

## 🎬 Step-by-Step Setup

### 1️⃣ Create Google Sheet (30 seconds)
```
1. Go to sheets.google.com
2. Click "+ Blank" to create new sheet
3. Name it "Class Attendance"
```

### 2️⃣ Add the Script (2 minutes)
```
1. In your sheet: Extensions → Apps Script
2. Delete existing code
3. Copy code from attendance-script.gs
4. Paste it in the editor
5. Click Save icon 💾
6. Name it "Attendance System"
```

### 3️⃣ Initialize & Authorize (2 minutes)
```
1. Close Apps Script tab
2. Refresh your Google Sheet (F5)
3. New menu appears: "📋 Attendance System"
4. Click: 📋 Attendance System → 🆕 Initialize Sheets
5. Click "Continue" when prompted
6. Select your Google account
7. Click "Advanced" → "Go to Attendance System"
8. Click "Allow"
```

### 4️⃣ Start Using! (30 seconds)
```
1. Click: 📋 Attendance System → ➕ Add Today's Date
2. Mark attendance: P = Present, A = Absent, L = Late
3. Click: 📋 Attendance System → 📊 Generate Summary
```

## 🎯 Daily Workflow

**Morning Routine:**
1. Open your attendance sheet
2. Click "Add Today's Date"
3. Click "Auto-fill Present" (marks everyone present)
4. Change any students who are absent/late

**Weekly Review:**
1. Click "Generate Summary"
2. Review attendance percentages
3. Contact students with low attendance

## 💡 Quick Tips

- **Keyboard shortcuts**: Type P, A, or L directly in cells
- **Dropdown available**: Click cell to see dropdown menu with options
- **Mobile friendly**: Works on Google Sheets mobile app
- **Auto-saves**: Google Sheets saves automatically

## 🎨 Understanding Colors

**In Attendance Sheet:**
- 🟢 Green background = Present (P)
- 🔴 Red background = Absent (A)
- 🟡 Yellow background = Late (L)

**In Summary Sheet:**
- 🟢 Green = 90%+ attendance (Excellent)
- 🟡 Yellow = 75-89% attendance (Good)
- 🔴 Red = Below 75% attendance (Needs attention)
